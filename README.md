 

# Khota | خُطى

Khota is a graduation project at King Saud University.
It is a mobile application that allows citizens to report
sidewalk and curb ramp issues in Riyadh by submitting photos
and locations and tracking their reports.

## Technologies

- Flutter and Dart
- Firebase Authentication
- Cloud Firestore
- Firebase Storage
- flutter_map and OpenStreetMap
- Geolocator

## Setup and Run

1. Install Flutter and set up the development environment.
2. Clone the repository:

    git clone https://github.com/hcchly/Khota.git

3. Open the project folder:

    cd Khota

4. Install the required packages:

    flutter pub get

5. Run the application in Chrome:

    flutter run -d chrome

The application requires the Khota Firebase configuration
and appropriate access permissions.

## Testing

Run the Flutter tests using:

    flutter test
